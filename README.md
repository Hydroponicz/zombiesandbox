# Zombie Sandbox (working title)

Single-player persistent open-world zombie survival, 2032 USA.
Sandbox survival meets lethal, realistic gunplay. First/third person.

- Engine: Godot 4.7.x (Forward+, Jolt physics)
- Design: see [DESIGN.md](DESIGN.md)

## Running
1. Open Godot 4.7.x → Import → select `project.godot` in this folder.
2. Press F5. You should see the graybox test range.

## Branches
- `main`: tested builds
- `preview`: new, untested work
